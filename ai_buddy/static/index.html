    MCP servers

    Skills from MCP servers. Switching one on connects it; its tools that change something ask you first.

      Add a server

      Add an entry like this to config.toml (a command that starts the server, or url = "…" for one that's already running), then reload. Keep tokens out of config.toml: put NAME=value in ~/.local/share/ai-buddy/secrets.env and write ${NAME}.

      [mcp.servers.weather]
command = "npx"
args = ["-y", "some-weather-mcp-server@1.0.0"]
description = "Forecasts from the weather service"
